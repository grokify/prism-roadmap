# v0.22.0

**Release Date:** 2026-11-01

## Highlights

- **DMAIC joins OKR and V2MOM in `goals`.** `goals/dmaic` models DMAIC (Define, Measure, Analyze, Improve, Control) metrics documents: categories of metrics, each in a DMAIC phase, with baselines, current values, targets, Six Sigma control limits and process capability, root causes, and the initiatives that improve them. It comes with validation presets, Marp and Pandoc renderers, and a generated JSON Schema.

## Overview

The OKR and V2MOM types came to prism-roadmap from structured-goals earlier, so
that one set of goal types serves every level of cascading planning. DMAIC was
the one framework left behind. With this release every goal framework lives in
`goals`, and structured-goals is deprecated.

See the [DMAIC guide](../goals/dmaic.md).

## Changes

### goals/dmaic

- `DMAICDocument`, `Category`, `Metric`, `ControlLimits`, `Thresholds`, `ProcessCapability`, `DataPoint`, `RootCause`, and `Initiative`, with `ReadFile`, `Parse`, and `WriteFile`.
- Health and status: `CalculateOverallHealth`, `CalculateCategoryHealth`, `Metric.CalculateStatus`, and `Metric.IsInControl`.
- Validation with three presets: `DefaultValidationOptions`, `StrictValidationOptions`, and `SixSigmaValidationOptions`.
- Renderers in `goals/dmaic/render/marp` (slides) and `goals/dmaic/render/pandoc` (Markdown for PDF or Word).

### Schema

`schema/dmaic.schema.json` is generated from the DMAIC types and embedded as
`schema.DMAICSchema()` and `schema.DMAICSchemaBytes()`. The opportunity
assessment and opportunity rank schemas are regenerated to match their Go types.

### Examples

Fictional DMAIC documents for manufacturing, software development, and customer
service are in `examples/*.dmaic.json`, and a test checks that each validates.

### Dependencies

- `github.com/grokify/priority-frameworks` v0.2.0 → v0.4.0
- `github.com/modelcontextprotocol/go-sdk` v1.7.0 → v1.8.0

## Moving from structured-goals

Change the import paths. The JSON is the same.

| structured-goals | prism-roadmap |
|------------------|---------------|
| `github.com/grokify/structured-goals/okr` | `github.com/grokify/prism-roadmap/goals/okr` |
| `github.com/grokify/structured-goals/v2mom` | `github.com/grokify/prism-roadmap/goals/v2mom` |
| `github.com/grokify/structured-goals/dmaic` | `github.com/grokify/prism-roadmap/goals/dmaic` |

## Compatibility

Additive only. An API comparison against v0.21.0 reports the new packages and
schema functions as compatible changes, and no incompatible changes.
