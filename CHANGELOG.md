## [v0.17.0] - 2026-08-15

### Highlights

- MoSCoW prioritization on RoadmapItem is now optional: empty means "not yet prioritized," honestly representing items imported from an external PM tool before triage, instead of silently defaulting to should_have
- OKR objective/key-result linking: RoadmapItem gains ObjectiveRefs/KeyResultRefs, and RICEByObjective rolls up prioritized (RICE-scored) work per OKR objective, surfacing coverage gaps and unlinked scored work
- v2mom and continuous-discovery OST templates/rubrics land in their canonical home here, upstreamed from downstream local copies
- assumption-map, bmc, and discovery-snapshot rubrics migrated to the canonical structured-evaluation rich format (id, passCriteria.maxFindingsSeverity) — the same fix downstream consumers had been applying locally
- RICE Validate() now rejects unrecognized (non-empty) impact/confidence levels instead of silently falling back to a default multiplier

### Added

- RoadmapItem.ObjectiveRefs/KeyResultRefs, AddObjectiveRef/AddKeyResultRef/SupportsObjective ([`6c5a24c`](https://github.com/grokify/prism-roadmap/commit/6c5a24c))
- rmi.RICEByObjective and rmi.UnlinkedScoredItems for rolling up RICE-scored items per OKR objective ([`6c5a24c`](https://github.com/grokify/prism-roadmap/commit/6c5a24c))
- prioritization.ImpactLevel/ConfidenceLevel gain IsValid() and ParseImpactLevel()/ParseConfidenceLevel() ([`2d74dd9`](https://github.com/grokify/prism-roadmap/commit/2d74dd9))
- v2mom family templates and rubrics (vision, values, methods, obstacles, measures, alignment, summary) and the continuous-discovery OST template/rubric ([`ae5fc41`](https://github.com/grokify/prism-roadmap/commit/ae5fc41))

### Changed

- rmi.RoadmapItem.MoSCoW is optional: empty means "not yet prioritized" (e.g. items imported from an external PM tool before triage). Validate() only checks MoSCoW against the valid-priority set when it's set ([`e25f0df`](https://github.com/grokify/prism-roadmap/commit/e25f0df))
- rmi.Service.Create no longer silently defaults an empty MoSCoW to should_have — empty persists as unset. The splan CLI's --moscow flag still defaults to should_have; pass --moscow="" for an explicit unprioritized item ([`e25f0df`](https://github.com/grokify/prism-roadmap/commit/e25f0df))
- RICEScore.Validate() rejects a non-empty, unrecognized Impact or Confidence value instead of silently applying a default multiplier ([`2d74dd9`](https://github.com/grokify/prism-roadmap/commit/2d74dd9))
- assumption-map, bmc, and discovery-snapshot rubrics rewritten from the intermediate flat format (spec_type key, no id, no passCriteria) to native structured-evaluation rich format ([`ededc57`](https://github.com/grokify/prism-roadmap/commit/ededc57))
